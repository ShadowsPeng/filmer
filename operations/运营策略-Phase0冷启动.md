# Filmer 运营策略 · Phase 0 冷启动手册

> 版本:v1.0 · 2026-07-24 · 宋润芃
> 适用阶段:0 → 1 万精准用户(约 6 个月)
> 战略前提:**砍掉五模块大盘子,聚焦一个能单人运营、且高频的楔子**

---

## 0. 为什么是这个楔子(先对齐战略,再谈打法)

BRD 里的"社区+电商+租赁+会员+冲扫"五线并进,单人运营带不动、冷启动鸡生蛋无解。本手册只做一件事:

> **上海本地胶片玩家的「冲扫内容社区 + 冲扫团单」**
> 用高频的**内容**聚人,用低频但刚需的**冲扫团单**变现和沉淀供给。

三个不做(Phase 0 明确砍掉):

- ❌ C2C 相机/胶卷租赁(信任+风控+押金资金池是火药桶,删)
- ❌ 会员订阅(没留存谈订阅是空的)
- ❌ 全国平台撮合(先做透上海一个城,再复制)

选它的底层理由:

1. **供给你自己就能对接**——你在上海、玩哈苏、有圈层,第一批冲扫店和 KOL 你能直接谈。
2. **内容和你的个人目标同源**——你 2026 本来就要做小红书胶片省钱攻略,内容即获客,不用两头烧钱。
3. **冲扫低频不要紧**——让内容扛高频活跃,冲扫扛变现,而不是反过来用冲扫扛 DAU。

## 1. 目标用户与人群分层

### 1.1 精准人群(全部锁定在上海 + 长三角可寄)

| 分层            | 画像                   | 核心痛点              | 我们给什么                |
| ------------- | -------------------- | ----------------- | -------------------- |
| **新手(入坑<1年)** | 18-26,学生/职场新人,刚买胶片机  | 不知道去哪冲、怕被坑、看不懂价格  | 冲扫避坑指南 + 透明比价 + 新手团单 |
| **进阶(1-3年)**  | 25-32,有固定机身,月拍 2-5 卷 | 想要稳定质量、好色彩、快返图    | 优选店背书 + 团单省钱 + 进度可视  |
| **老法师/摄影师**   | 30+,哈苏/中画幅/反转片       | 要高质量扫描(哈苏X5)、懂行的店 | 高端扫描店对接 + 专业社群       |

**Phase 0 主攻中间层(新手 + 进阶)**,老法师作为内容 KOL 来源和口碑背书,不作主要付费群。

### 1.2 冷启动只服务一个地理圈:上海

先做透一座城,把"上海冲胶片认准 Filmer"打出来,再谈复制杭州/南京/成都。全国铺开是 Phase 0 之后的事。

## 2. 北极星指标与数据体系(先定义,才能运营)

### 2.1 北极星指标

> **月度完成冲扫团单的活跃用户数(月付费冲扫人数)**

不是注册数、不是 DAU——这是唯一能证明"内容→变现"闭环成立的指标。

### 2.2 指标树(每一层都要埋点)

```
北极星:月付费冲扫人数
├── 获客:小红书内容曝光 → 主页访问 → 加私域/进群
│     指标:笔记曝光量、涨粉数、私域新增
├── 激活:进群后 7 天内下第一单
│     指标:首单转化率、下单前咨询转化
├── 留存:冲扫复购(30/60/90 天)
│     指标:次月复购率、平均下单间隔
├── 变现:客单价 × 抽佣率
│     指标:GMV、平台毛利、单均毛利
└── 推荐:老用户带新(晒片带话题、拼团)
      指标:分享率、拼团成团率、邀请转化
```

### 2.3 数据地基(极简,不上重后台)

- Phase 0 **不建 CMS**,用飞书多维表格做订单台账 + 用户台账(你本机就有 lark-cli,能直接写飞书表)。
- 小红书数据每周手动抄进同一张表:曝光/涨粉/私域新增。
- 每周日 30 分钟复盘:漏斗哪一层漏水最狠,下周只补那一层。

## 3. 冷启动:0 → 1000 精准粉(第 1-8 周)

### 3.1 核心打法:内容即获客,你自己是 0 号 KOL

**主阵地小红书,单点突破。** 不要一开始铺全平台。

#### 内容三大支柱(选题库,直接照拍)

**A. 避坑/比价(涨粉利器,占 40%)**

- 「上海冲一卷胶片到底多少钱?我跑了 8 家店做了张价格表」
- 「劝退!这 3 种冲扫店千万别去(附返图翻车对比)」
- 「135 vs 120 冲扫价差在哪?一张图讲清」

**B. 干货/教程(建立专业度,占 30%)**

- 「胶片拍完到拿到扫描图,完整流程 + 每步花多少钱」
- 「C-41 / E-6 / 黑白 到底啥区别,新手别选错工艺」
- 「同一卷 Portra 400,3 家店扫出来差多少?」(实测对比,爆款相)

**C. 晒片/氛围(引发共鸣+涨粉,占 30%)**

- 你自己的哈苏原片,不加滤镜(符合你审美),配"上海 XX 路扫街"
- 「我的第一卷 vs 现在」成长叙事

#### 发布节奏

- **每周 3 更**(周二/周五/周日晚 7-9 点),坚持 8 周 = 24 篇。
- 每篇结尾统一钩子:「评论区扣『冲扫』,拉你进上海胶片冲扫避坑群」——**把公域流量导进私域**,这是命根子。

### 3.2 私域是主战场(公域获客,私域成交)

- 建「上海胶片冲扫交流群」微信群,群公告 = 优选店清单 + 本周团单。
- 群内高频动作:每天 1 条(晒片/答疑/店家动态),保持温度。
- **不在群里硬广**,靠答疑和真实测评建立信任,下单靠团单接龙自然发生。

### 3.3 KOL/供给冷启动(用置换,不花钱)

- 你先做出 5-10 篇有数据的内容,拿着数据去谈 3-5 个上海本地胶片博主**互推**(你帮他导冲扫需求,他帮你曝光)。
- 老法师 KOL 用「免费高端扫描测评名额」置换一篇晒片笔记。

**第 8 周退出标准:私域 ≥ 500 人,累计完成 ≥ 30 单团单。**

## 4. 供给侧运营(平台的真正壁垒,别只顾 C 端)

撮合平台死于供给。这一节是重点。

### 4.1 首批只签 3 家,分层覆盖

| 层级                 | 数量    | 用途            | 谈判抽佣                          |
| ------------------ | ----- | ------------- | ----------------------------- |
| 走量店(C-41 标准冲扫,性价比) | 1-2 家 | 承接新手/进阶主流团单   | 起步 **8-10%**(别学 BRD 上来就要 15%) |
| 高端扫描店(哈苏X5/诺日士)    | 1 家   | 老法师、专业需求、内容背书 | 单独议,可先 0 抽佣做口碑                |

### 4.2 你能给冲扫店什么增量(谈判话术核心)

成熟店有淘宝+私域,凭什么上你?答案只有一个:**你带来它自己触达不到的增量订单,且是批量团单(降低它的沟通成本)**。

- 话术:「我一个群 500 个上海本地胶片用户,每月给你打包送 X 卷团单,你只管冲、我负责获客和客服。」
- 前期抽佣压到 8-10%,甚至第一个月免佣跑通流程,用**订单量**换它的配合。

### 4.3 供给侧 SLA(白纸黑字写进合作)

- 返图时效:收件后 **3-5 个工作日**,超时你要能给用户交代。
- 质量兜底:返图翻车(划痕/色偏/丢卷)的责任划分和重扫/赔付规则,签合作时就定死。
- 结算:**周结或半月结**,线下对账(Phase 0 不做自动分账),你先垫付/代收都行,但账要日清。

### 4.4 质量管控(平台口碑的生死线)

- 每家店每月抽检:你自己送 1-2 卷做盲测,比对返图质量。
- 群内收集真实评价,差评店直接下架——**你的信用是平台唯一资产,不给烂店背书**。

## 5. 变现与单元经济模型(把账算清,别拍脑袋)

### 5.1 收入来源(Phase 0 只做一条)

> **冲扫团单抽佣**。其余全部延后。

### 5.2 单笔经济模型(示例,数字按实际调)

| 项           | 数值       |
| ----------- | -------- |
| 单卷冲扫均价(用户付) | ¥25      |
| 平台抽佣率       | 10%      |
| 单卷平台毛利      | ¥2.5     |
| 团单平均卷数/单    | 3 卷      |
| **单均毛利**    | **¥7.5** |

**残酷的现实**:这个盘子的抽佣毛利极薄。所以 Phase 0 的目标**不是赚钱,是验证"内容能否稳定转化成冲扫订单"这个闭环**。真正的钱在后面——闭环跑通后,靠周边电商(高毛利标品:收纳、暗袋、相册)和实体输出(银盐打印/装裱,毛利 50%+)变现,冲扫只是**引流入口和信任入口**。

### 5.3 复购设计(冲扫低频,靠这几招拉高频次)

- **拼团接龙**:群内每周固定「周三团单」,凑单免运费,制造节奏感。
- **进度可视**:下单后你在群里同步"已送冲/已扫描/已返图",低频服务用透明感建立复购信任。
- **晒片激励**:返图后引导用户在群/小红书晒片带话题,晒片者下单立减,形成 UGC + 复购双飞轮。

## 6. 单人运营的时间分配(现实约束下的排班)

你是兼职,每天有限时间,必须结构化:

| 时间块       | 事项             | 时长                       |
| --------- | -------------- | ------------------------ |
| 每天早/午(碎片) | 群内答疑、订单跟进、店家沟通 | 30-45 分钟                 |
| 每周二/五/日晚  | 小红书内容生产+发布     | 各 60-90 分钟(正好用你的单任务专注时间) |
| 每周三       | 团单接龙 + 送冲 + 对账 | 60 分钟                    |
| 每周日       | 数据复盘 + 下周选题规划  | 30 分钟                    |

**能自动化就自动化**:订单台账用飞书表 + lark-cli 自动录入;返图通知用群机器人。别把自己耗在重复劳动上。

## 7. 增长:1000 → 10000(第 9-24 周)

跑通闭环后再加杠杆,顺序不能乱:

1. **内容加杠杆**:把爆款笔记结构化复用,开始投小红书薯条(小额测 ROI,单篇 ¥100 测,跑正了再加)。
2. **私域裂变**:老带新——邀请 3 人进群得冲扫券;拼团满 X 人解锁更低价。
3. **供给扩容**:上海店从 3 家扩到 8-10 家,按工艺/区域分层,支撑更大订单量。
4. **品类延伸**:上高毛利周边电商(标品一件代发)+ 实体输出,提升客单和毛利。
5. **城市复制**:上海模型跑正后,用同一套 SOP 复制杭州/南京(有胶片用户基础的城市)。

**不要在闭环没跑通前做任何一条上面的加杠杆动作**——放大一个亏损的漏斗只会亏更快。

## 8. 风险与合规(踩了就出局的红线)

| 风险        | 等级   | 对策                                |
| --------- | ---- | --------------------------------- |
| 押金资金池     | 🔴 高 | Phase 0 不做租赁、不碰押金,从根上避开           |
| 丢卷/翻车纠纷   | 🔴 高 | 供给 SLA + 赔付规则签死;高价值卷(反转片)提示风险、可拒接 |
| 收款合规      | 🟡 中 | 团单先用个人收款过渡,GMV 起来立刻办个体户 + 微信商户号   |
| 平台给烂店背书翻车 | 🟡 中 | 月度盲测 + 差评即下架                      |
| 你一个人扛不住   | 🟡 中 | 严守"三个不做",不发散新支线;客服高峰找兼职           |
| 内容平台限流/封号 | 🟢 低 | 私域为主阵地,公域只做获客;不把身家押在单一平台          |

## 9. 90 天执行计划(照着打勾)

### 第 1-2 周:地基

- [ ] 定选题库(照第 3.1 节,先囤 12 篇选题)
- [ ] 谈下第 1 家走量冲扫店(签 SLA + 抽佣)
- [ ] 建私域群 + 群公告模板 + 飞书订单台账
- [ ] 发布前 3 篇小红书(避坑/比价方向先行)

### 第 3-6 周:跑闭环

- [ ] 稳定每周 3 更,涨粉进私域
- [ ] 跑通第一批团单(哪怕 3 单),全程记录问题
- [ ] 签第 2、3 家店(补高端扫描)
- [ ] 每周复盘漏斗,定位最漏的一层

### 第 7-12 周:验证 + 微调

- [ ] 私域 ≥ 500,累计团单 ≥ 30
- [ ] 首单转化率、次月复购率两个数摸出来
- [ ] 跑通拼团接龙 + 晒片激励飞轮
- [ ] 决策:闭环是否成立 → 成立则进入增长期加杠杆;不成立则调楔子
