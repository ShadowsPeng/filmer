### 2.2 线下合作资源

#### 🏪 冲扫店（必须）

冲扫服务是平台核心业务线之一，需提前对接 2-3 家：

| 要求 | 说明 |
|---|---|
| 工艺覆盖 | 必须支持：C-41负片、E-6反转片、黑白冲洗 |
| 扫描格式 | 至少提供 TIFF / JPEG 高质量扫描 |
| 响应速度 | 接单后 3-5 天内完成 |
| 地理位置 | 优先一线城市（有胶片用户基础） |
| 合作意愿 | 愿意接受平台抽佣（10-15%）和线上订单系统 |

**建议对接方向：**
- 画英雄（杭州/上海，有品牌）
- 感光故事（淘宝有店，全国可寄）
- 各城市本地冲扫店（小红书搜索「你的城市 + 冲洗胶片」）

#### 📠 扫描店（必须）

部分冲扫店不含扫描，或用户需要更高质量输出（如哈苏X5扫描）：

| 要求 | 说明 |
|---|---|
| 扫描仪型号 | 哈苏X5 > 诺日士 > 精益（价格和质量正相关） |
| 输出格式 | 16bit TIFF、AdobeRGB |
| 服务类型 | 可接受单独扫描委托（不冲只扫） |

**建议对接方向：**
- 上海：映画馆、APS
- 北京：胶片时代、光盐
- 广深：大熊座、菲林日记
- 可寄送服务：感光故事（淘宝）

#### 📦 胶卷/周边供应商（电商变现用）

前期不做自库存，走代发模式，对接以下渠道：

| 类型 | 渠道 |
|---|---|
| 胶卷（135/120） | 感光故事（淘宝）、影视狗、有赞代理 |
| 冲洗套药 | 淘宝中小店家（显影液/定影液，标品） |
| 周边器材 | 淘宝一件代发（胶卷盒、暗袋、冲洗罐） |
| 反转片 | 极难找，预售+团购模式，慎入 |

### 2.3 工商资质

| 资质 | 是否必须 | 说明 |
|---|---|---|
| **个体工商户营业执照** | ⚠️ 建议 | 做平台抽佣需要收款通道，个人收款有限额；注册个体户成本约 ¥200-500，1周下证 |
| **企业营业执照** | ❌ 暂不需要 | 初期没必要，等规模大了再升级 |
| **食品/药品许可** | ❌ 不需要 | 胶卷不是食品药品，不需特殊许可 |
| **出版物经营许可** | ❌ 不需要 | 胶卷不属于出版物 |
| **网络文化经营许可证（文网文）** | ⚠️ 视情况 | 如果平台做「用户内容付费」可能需要；纯抽佣模式暂时不用 |
| **ICP 备案/许可证** | ⚠️ 必须 | 网站/小程序上线必须，建议用公司主体做ICP备案（个体户可申请） |
| **微信支付商户号** | ⚠️ 必须 | 收取用户付款需要，有营业执照才能申请企业版商户号 |

**最低资质配置（Phase 0）：**
```
个体工商户营业执照 + ICP备案 + 微信商户号（企业版）
≈ 成本 ¥200-500 + 1周时间
```

### 2.4 人力资源

| **前端开发** | 小程序 + APP（Taro） | 建议外包，¥5000-15000 能做完 MVP |
