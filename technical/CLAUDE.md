## 技术栈（已在 README.md 确认）

- 前端：**微信小程序 + APP**（Taro 4.x + React，一套代码编译到双端）
- 后端：Node.js + Koa 2.x
- 数据库：MySQL 5.7 + Prisma
- 发版：GitHub Actions + PM2 热更新
- 预算：¥3000-5000，首年实际支出约 ¥639

> Taro 4.x 支持同时编译到微信小程序和 React Native（APP），UI 复用，业务逻辑复用，开发成本接近单端。

---

## 关键约定

1. **不碰库存**：所有电商/租赁走代发或 C2C 撮合，不垫资采购
2. **先社区后变现**：Phase 0 只做内容社区，变现功能 Phase 1 再上
3. **小程序先行**：APP 是后期选项，MVP 只做微信小程序
4. **生成即打开**：前端文件生成后直接在浏览器/微信开发者工具预览
5. **抽佣优先**：所有业务线优先走抽成模式，不自营
