## 一、胶片画幅规格

### 1.1 135 画幅（35mm）

最常见的胶片格式，齿孔在两侧。

| 规格                  | 画面尺寸      | 说明                        |
| ------------------- | --------- | ------------------------- |
| **全画幅（Full Frame）** | 36×24mm   | 标准135，齿孔间距3.175mm         |
| **半画幅（Half Frame）** | 18×24mm   | 一张135可拍72张，Olympus PEN 系列 |
| **APS-H**           | 28.7×19mm | 胶片时代的旗舰格式，已停产             |
| **110 画幅**          | 13×17mm   | 口袋相机用，已基本淘汰               |

**常见135胶卷型号：**

- Kodak：Portra 400/160/800、Gold 200、Ektar 100、Tri-X 400、HP5 Plus
- Fuji：Pro 400H、C200、Superia 400、Velvia 50/100、Provia 100F
- Ilford：HP5 Plus 400、Delta 100/400、FP4 Plus 125
- Lomography：400/800/Color negative 系列

## 二、胶片类型

### 2.1 按感光度（ISO）分类

| 类型       | ISO 范围       | 特点            | 典型场景       |
| -------- | ------------ | ------------- | ---------- |
| **低感光度** | ISO 25-100   | 细腻、颗粒极低、需充足光线 | 风光、产品摄影、影棚 |
| **中感光度** | ISO 200-400  | 平衡型，室内外皆可     | 人像、日常记录    |
| **高感光度** | ISO 800-3200 | 高光敏感、颗粒粗、夜间可用 | 夜拍、演出、体育   |

---

### 2.2 按成像颜色分类

#### 【负片（Negative Film）】

最常见的胶片类型，拍出来是彩色负像（颜色反转，明暗反转）。

| 类型            | 代表产品                            | 冲洗工艺          |
| ------------- | ------------------------------- | ------------- |
| **彩色负片**      | Kodak Portra、Fuji Pro 400H      | C-41          |
| **黑白负片**      | Ilford HP5 Plus、Kodak Tri-X 400 | D-76 / HC-110 |
| **彩色负片（电影卷）** | Kodak Vision3 5207/5219         | C-41（电影专用配方）  |

#### 【反转片（Slide / Reversal Film）】

冲洗后直接得到正像（和最终照片颜色一致），需光源观看或扫描。

| 类型        | 代表产品                          | 冲洗工艺   |
| --------- | ----------------------------- | ------ |
| **彩色反转片** | Fuji Velvia 50/100、Kodak E100 | E-6    |
| **黑白反转片** | 极少见，Ilford R40 等              | 专用反转工艺 |

#### 【一次成像（Instant）】

| 类型                  | 代表产品                        | 说明          |
| ------------------- | --------------------------- | ----------- |
| **Polaroid（宝丽来）**   | Polaroid 600/Spectra/i-Type | 即时成像，机身直接吐出 |
| **Fujifilm Instax** | mini/wide/Square            | 富士即时成像，量大便宜 |

## 三、冲洗工艺

### 3.1 C-41（彩色负片冲洗）

**适用**：所有彩色负片（Portra、Gold、Superia、Pro 400H 等）

| 参数    | 标准值                  |
| ----- | -------------------- |
| 显影温度  | 38°C（100.4°F）±0.15°C |
| 显影时间  | 约3分15秒               |
| 总流程时间 | 约17分钟（显影+漂白+定影+水洗）   |

> C-41是标准化程度最高的冲洗工艺，全世界任何一家冲扫店都能做。

#### 市面常见C-41冲洗套药

| 品牌    | 产品                | 说明       |
| ----- | ----------------- | -------- |
| Kodak | Flexicolor（粉末/液体） | 工业级，最稳定  |
| 不知名品牌 | 散装套药              | 质量参差，不推荐 |

---

### 3.2 E-6（彩色反转片冲洗）

**适用**：所有彩色反转片（Velvia、E100、Provia 等）

| 参数    | 标准值         |
| ----- | ----------- |
| 显影温度  | 38°C ±0.3°C |
| 显影时间  | 约6分钟（首显）    |
| 总流程时间 | 约30分钟       |

> E-6工艺比C-41复杂，国内能做E-6的冲扫店比C-41少很多，很多需要寄到特定地点。

#### E-6 冲扫难点

- 温度控制要求更严
- 反转片对曝光误差容忍度极低（±1/3档内）
- 国内能做E-6的冲扫店：北京胶片时代、上海映画馆、广州大熊座等

---

### 3.3 黑白冲洗（D-76 / HC-110 等）

**适用**：所有黑白胶卷（Tri-X、HP5 Plus、Delta 等）

| 冲洗方式                      | 套药              | 说明          |
| ------------------------- | --------------- | ----------- |
| **D-76（标准显影）**            | Kodak D-76 粉末   | 最经典，颗粒细腻    |
| **HC-110（快速显影）**          | Kodak HC-110 液体 | 显影时间短，稀释后使用 |
| **Rodinal（rodinal）**      | Agfa Rodinal 液体 | 极高锐度，极粗颗粒   |
| **Ilford ID-11**          | Ilford ID-11 粉末 | 接近D-76      |
| **液显（Stand Development）** | 任意              | 一小时显影，极粗颗粒  |

> 黑白冲洗是唯一可以自己在家完成的冲洗工艺（只要有显影罐+计时器+药膜）。

---

### 3.4 冲洗工艺对比

| 工艺              | 适用胶片  | 温度要求        | 难度       | 国内可做店铺数 |
| --------------- | ----- | ----------- | -------- | ------- |
| **C-41**        | 彩色负片  | 38°C ±0.15° | 低（自动化机器） | 非常多     |
| **E-6**         | 彩色反转片 | 38°C ±0.3°  | 中（专用设备）  | 少，需寄送   |
| **D-76/HC-110** | 黑白负片  | 20°C ±0.5°  | 低（可自己动手） | 任何一家    |

## 五、胶片摄影基础参数

### 5.1 感光度与光线关系

| 光线条件       | 推荐ISO         |
| ---------- | ------------- |
| 阳光充足（户外白天） | ISO 50-100    |
| 多云/阴天户外    | ISO 200-400   |
| 室内自然光      | ISO 400-800   |
| 夜景/演出/室内运动 | ISO 800-3200+ |

### 5.2 互易律失效（倒易律失效）

> 长时间曝光时（>1秒），胶片实际感光度会下降，需要"倒易律补偿"增加曝光时间。

| 标称曝光时间 | 实际应增加曝光     | 品牌补偿曲线     |
| ------ | ----------- | ---------- |
| 1秒     | +1档（×2）     | Fuji建议+1档  |
| 10秒    | +2档（×4）     | Kodak建议+2档 |
| 30秒    | +2.5档（×5.7） | 因品牌而异      |

## 六、胶片专业术语

| 术语                        | 解释                                  |
| ------------------------- | ----------------------------------- |
| **颗粒（Granularity/Grain）** | 胶片影像的噪点，低ISO细腻，高ISO粗                |
| **宽容度（Latitude）**         | 胶片能记录的明暗范围，负片宽容度约5-7档，反转片约2-3档      |
| **倒易律（Reciprocity）**      | 曝光量=光强度×时间，长时间曝光需补偿                 |
| **药膜/乳剂（Emulsion）**       | 胶片上涂布感光化学物质的层                       |
| **齿孔（Sprocket Hole）**     | 135胶卷两侧的运输孔                         |
| **暗角（Vignetting）**        | 画面边缘变暗，广角/大光圈易出现                    |
| **光晕（Halation）**          | 强光在胶片上产生的泛光，红/橙常见                   |
| **漏光（Light Leak）**        | 光线意外进入胶片，产生不规则光斑                    |
| **静电痕迹（Static Marks）**    | 胶片摩擦产生静电放电，在片基上留下树枝状痕迹              |
| **C-41**                  | 彩色负片标准冲洗工艺                          |
| **E-6**                   | 彩色反转片标准冲洗工艺                         |
| **D-76**                  | 经典黑白显影液配方                           |
| **迫冲（Push）**              | 按高于胶卷标称ISO拍摄，强行提升感光度（如ISO400卷当800用） |
| **迫冲（Pull）**              | 按低于胶卷标称ISO拍摄（如ISO400卷当200用），降低颗粒    |
| **迫冲（Push Processing）**   | 冲洗时延长显影时间，补偿迫冲带来的密度损失               |
| **哈苏X5**                  | 专业底片扫描仪，以高光保留和色彩还原著称                |
| **诺日士**                   | 商业冲扫店最常见的自动冲片机+扫描仪                  |

## 七、胶片保存与过期

### 7.1 保存条件

| 类型        | 理想条件              | 警告                 |
| --------- | ----------------- | ------------------ |
| **未拍胶卷**  | 冷冻（-10°C以下）+ 密封防潮 | 冷藏（4°C）次之，不可高于20°C |
| **已拍未冲洗** | 尽快冲洗，拍摄后48小时内     | 高温会加速潜影衰退          |
| **已冲洗负片** | 常温干燥避光            | 彩色负片会随时间褪色（15-20年） |
| **反转片**   | 冷冻+密封，彩色反转片可保存数十年 | 冷冻后需缓慢回温防止凝露       |

### 7.2 过期胶卷

| 过期时间  | 影响          | 可用性           |
| ----- | ----------- | ------------- |
| 1年内   | 基本无影响（冷藏保存） | 完全可用          |
| 1-3年  | 轻微色彩偏移/颗粒变粗 | 可用，部分场景有"复古感" |
| 3-5年  | 明显色彩偏移、反差降低 | 可用，常用于创意拍摄    |
| 5年以上  | 严重褪色、灰雾、颗粒粗 | 可用，但效果不可预测    |
| 10年以上 | 极可能严重损坏     | 高风险，需测试       |

## 八、胶片与数码的画质对比

| 维度        | 胶片优势                        | 数码优势               |
| --------- | --------------------------- | ------------------ |
| 动态范围（宽容度） | 负片宽容度大（7档+），高光阴影兼得          | 单反/DSP动态范围已超过胶片    |
| 高感表现      | 高感颗粒≠噪点，视觉接受度高              | 高感控噪能力强            |
| 色彩科学      | 厂商色彩风格鲜明（Portra肤色、Velvia饱和） | 可后期任意调整            |
| 细节分辨率     | 135约等效4000万像素，120等效1亿+      | 全画幅旗舰已达1亿+像素       |
| 后期灵活性     | 低                           | 高（RAW文件信息量远大于扫描文件） |
| 即时性       | 低（需冲洗后才能看到）                 | 高（所见即所得）           |
| 收藏价值      | 高（实体影像）                     | 低                  |
