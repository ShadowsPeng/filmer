## 五、容易被忽略的"暗坑"

1. **微信开放平台账号 + 第三方平台全网发布**:未来要做 APP,必须先有「微信开放平台」账号并绑定小程序,否则 unionid 不通
2. **unionid 机制**:纯小程序阶段 openid 就够,但 Phase 1b 多端接入前必须把 unionid 字段加上(否则用户数据无法合并)
3. **支付回调幂等键**:任何支付系统的第一道防线就是幂等表。**本方案的 IdempotencyKey schema 已就位 ✅**
4. **支付日志审计**:金融级要求,每笔支付的「创建 / 回调 / 退款 / 对账」全链路日志保留 ≥5 年(OrderEvent + PaymentAttempt.rawNotify 是基础)
5. **商户号风控**:被同行恶意投诉或资金流异常会被微信风控封号。要预留「备用商户号」
6. **测试商户号**:调试期间必须用「微信支付测试号」和沙箱环境(v2 沙箱 / v3 测试用例),不要在生产号调试
7. **微信支付分(押金方案)**:2025 年微信支付分对个人开发者开放了部分场景,需重新确认胶片租赁押金是否在其覆盖范围内,**否则只能用预授权方案**
8. **冲扫店合作合同里的"结算条款"**:BRD §3.4.3 说"平台抽佣 10-15%"。要在合同里写清楚结算周期(T+7 / T+30)、发票流、退款冲账规则
