# 工商 & 微信支付入驻流程

> 这是一份**预先要知道**的清单 — 每一步都在等日历时间。
> 建议启动资金 / 资源到位后**立即**并行办理。

## 整体时间线(快的情况)

```
D 1-7   个体工商户营业执照
D 7-14  域名注册 + ICP 备案(省份差异大,广东上海可代办 7 工作日)
D 1-3   微信小程序账号注册 + 主体认证(企业或个人;MVP 必须企业)
D 3-10  微信支付商户号申请(提交营业执照后审核)
D 10-14 拿到 API v3 密钥 + 商户证书
合计:大约 2-4 周
```

## 1. 个体工商户营业执照

- 用途:开通企业版微信支付商户号必须;开 ICP 备案的主体
- 流程:本地市场监管局/政务服务中心办理;也可找代办,500-1000 元,7-10 工作日下证
- 提前准备:经营者身份证、经营场所证明(自有 / 租赁)
- 范围:核冲扫服务无需特殊许可(胶卷、显影液不属于食药/危化品),营业执照"经营范围"覆盖"摄影服务 / 零售"即可
- 拿到的是:**营业执照副本** + **统一社会信用代码**

## 2. 微信小程序账号 + 企业认证

- 注册:mp.weixin.qq.com,用营业执照上主体的对公邮箱
- 主体类型:**企业**(不要选个人,个人不能开通微信支付)
- 企业认证费:¥300/年(微信代收,认证时企业付款)
- 认证材料:营业执照、对公账户验证(小额打款 / 法人微信扫码)
- 7-15 工作日

## 3. 微信支付商户号

- 入口:pay.weixin.qq.com → 商户申请
- 必须:营业执照 + 法人身份证 + 结算银行账户(对公账户)
- 审核:1-5 工作日
- 通过后获得 **mch_id** 商户号

## 4. AppID 与商户号绑定

- 商户号 → 产品中心 → AppID 账号管理 → 关联 AppID
- 输入你已认证的小程序 AppID,验证主体一致

## 5. API v3 密钥 + 商户证书

- 商户平台 → API 安全 → 设置 APIv3 密钥(32 字节随机,自己生成)
- 商户平台 → API 安全 → 申请 API 证书 → 下载 `apiclient_cert.pem` + `apiclient_key.pem`(**仅此一次,丢失需重新申请**)
- 推荐:同时申请 **微信支付公钥** → 下载 `public_key.pem`(替代平台证书自动轮换)

## 6. 域名 + ICP 备案

- 域名:阿里云 / 腾讯云 / Cloudflare Registrar,¥40-60/年(.com)
- ICP 备案:主体需与营业执照一致(个体户也可),通过云服务商代备案入口办理(阿里云 / 腾讯云免费代备案),省/市有差异,通常 7-20 工作日
- 备案后申请免费 SSL(Let's Encrypt 自动)
- 域名最终状态:`https://filmer.example.com/` 通

## 7. 经营类目审核

- 小程序后台 → 设置 → 类目管理 → 添加类目
- 摄影服务类目常见要求:ICP 备案 + 一些资质文件,**因地而异**,别假设
- 类目审核通过前,微信支付接口会被风控拦截

## 并行办理建议

| 串行 | 并行 |
|---|---|
| 个体工商户(等本子) | 域名注册(当天) |
| 微信小程序账号(等微信审核) | 小程序代码开发(本地 mock 跑起来) |
| 商户号(等小程序认证) | 后端支付代码(本文档方案) |
| ICP 备案(等营业执照) | 设计稿 / VI 优化 |
| 类目(等小程序认证) | KOL 合作洽谈 |
