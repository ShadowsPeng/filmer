## 1. 项目背景与目标

### 1.1 项目背景（BRD 摘要）

胶片复兴趋势持续，国内 18-30 岁胶片用户增量显著，但市面上**没有**一款产品同时覆盖「内容社区 + 垂直电商 + C2C 租赁 + 会员订阅」四类场景。Filmer 要做胶片玩家的小红书 + 京东 + 滴滴租相机。

完整背景、商业模式、竞争分析见 `BRD-胶片影像平台.md`。本文档**只覆盖 MVP 阶段的产品功能需求**，不重复商业侧内容。

### 1.2 MVP 范围（Phase 0 + Phase 1）

> **MVP 定义：能让用户完成「种草 → 拍片 → 冲扫 → 晒片」最小闭环的所有功能。**

| 模块 | Phase | 必须上线 | 备注 |
|---|---|---|---|
| 内容社区（Feed / 发布 / 详情 / 评论 / 话题） | Phase 0 | ✅ | 核心流量入口 |
| 用户系统（注册 / 登录 / 主页） | Phase 0 | ✅ | 微信一键登录 + 手机号兜底 |
| 通知中心（点赞/评论/关注/系统） | Phase 0 | ✅ | 站内消息合并 |
| 相机 & 胶卷租赁库（浏览 + 详情 + 订单） | Phase 1 | ✅ | C2C 撮合 + 平台承担履约 |
| 胶片电商（商品库 + 详情 + 下单） | Phase 1 | ✅ | 初期一件代发，无库存 |
| 冲扫服务（店列表 + 委托下单 + 进度） | Phase 1 | ✅ | 联营冲扫店 |
| 会员体系（银会员订阅 + 权益） | Phase 1 | ✅ | 撬动租赁免押金的钩子 |
| KOL 入驻流程 | Phase 0 | ✅ | 冷启动关键 |
| 搜索 | Phase 1 | ✅ | 关键词 + 话题 + 用户 |
| 增值服务（订阅盒/银盐打印/防潮寄存/数据产品/品牌联名） | Phase 2+ | ❌ | 本文档不展开 |
| 金会员、直播、挑战赛 | Phase 2+ | ❌ |  |

### 1.3 MVP 非目标（Out of Scope）

- ❌ 数字滤镜、胶片模拟、相机内拍照
- ❌ 短视频、直播
- ❌ 自营冲扫产能
- ❌ 海外胶卷反向海淘
- ❌ 二手器材交易（仅做内容引流到闲鱼，不做撮合）
- ❌ PC 端、H5 公众号版本

## 2. 术语表

### 2.1 胶片专业术语

| 术语 | 英文 | 解释 |
|---|---|---|
| **胶卷 / 胶片** | Film | 用于相机拍摄的一次性成像介质 |
| **135 / 35mm** | 135 format | 标准 35mm 胶卷，一卷 36 张，画幅 24×36mm |
| **120** | 120 format | 中画幅胶卷，每卷 12/16 张，常见画幅 6×4.5、6×6、6×7、6×9 |
| **负片** | Negative | 冲洗后得到负像，需扫描/印相才能看，C-41 是彩色负片工艺 |
| **反转片 / 幻灯片** | Slide film | 冲洗后直接成正像，可放观片器看，E-6 是彩色反转片工艺 |
| **C-41** | C-41 | 彩色负片冲洗工艺（行业标准） |
| **E-6** | E-6 | 彩色反转片冲洗工艺 |
| **D-76** | D-76 | 经典黑白胶卷显影液 |
| **迫冲 / 增感** | Push process | 延长显影时间，把低 ISO 胶卷当高 ISO 拍（如 HP5 当 1600 拍） |
| **ISO / 感光度** | ISO | 胶卷对光的敏感度，数值越大越适合弱光 |
| **冲扫** | Develop & Scan | 冲洗 + 扫描，一站式服务 |
| **画幅** | Format | 胶卷成像区域大小 |
| **卷** | Roll | 一卷胶卷的计量单位 |
| **暗袋** | Changing bag | 不透光袋，用于装卸胶卷 |
| **齿孔 / 片孔** | Sprocket holes | 胶卷两侧的孔，用于过片 |

### 2.2 产品功能术语

| 术语 | 解释 |
|---|---|
| **笔记 / 发卷** | 用户发布的图文内容（电影感叫法，对应小红书的"笔记"） |
| **胶片信息卡** | 每张图挂载的胶卷/相机/工艺元数据 |
| **KOL** | 关键意见领袖，平台认证的胶片摄影师/博主 |

## 4. 用户故事与场景

### 4.1 核心 JTBD（Jobs To Be Done）

> **用户故事格式：当……（场景），我想要……（动机），以便……（结果）。**

#### 场景 A：新手种草-入坑

> 当我**在小红书看到别人用 Portra 400 拍的西湖**时，我想**知道这是什么相机、什么卷、怎么冲扫**，以便**自己也能拍出这样的照片**。

**对应需求**：笔记详情页胶片信息卡可点击 → 跳转「胶卷详情」/「相机详情」→ 一键购买胶卷 → 下单冲扫券。

#### 场景 B：老法师分享-社交

> 当我**拍完一卷 Portra 400 拿到返图**时，我想**发到社区让同好看到，并讨论参数**，以便**获得反馈、积累同好、可能接商单**。

**对应需求**：发布流程引导填写胶片信息卡 → Feed 曝光 → 评论互动 → KOL 认证路径。

#### 场景 C：设备党短期体验

> 当我**想试拍徕卡 M6 / 哈苏 500CM 但买不起**时，我想**按天租一台试试手感**，以便**决定是否购入二手**。

**对应需求**：租赁 Tab → 相机详情页（含押金/日租/损坏险）→ 下单 → 顺丰包邮到家 → 用完归还。

#### 场景 D：犹豫入坑低成本试错

> 当我**想入胶片坑但不知道买什么**时，我想**用 ¥199 拿一卷入门套装+教程+冲扫券**，以便**完整走一遍流程再决定**。

**对应需求**：新手订阅盒产品页 → 下单 → 收到实物 + 教程链接 → 引导拍第一卷。

### 4.2 关键用户旅程（User Journey Map）

#### 旅程 1：内容闭环（最高频）

```
打开 APP → 看 Feed（热门）→ 看到喜欢的笔记
  → 点进详情 → 看胶片信息卡 → 关注作者
  → 点击胶卷名 → 跳到电商商品页 → 加入购物车（可选）
  → 点击冲扫店 → 跳到冲扫店详情 → 收藏（可选）
  → 返回首页 → 切到「我的」看关注的更新
```

#### 旅程 2：租赁闭环（高客单价）

```
打开 APP → 切到「租赁」Tab
  → 选「相机」/「胶卷」二级分类
  → 筛选（品牌/价格/画幅）→ 浏览列表
  → 点进详情 → 看押金/日租/成色 → 选择日期（3/7/15 天）
  → 加购 → 进入订单确认 → 选是否购买损坏险
  → 支付（押金 + 租金 + 保险）→ 等待发货
  → 收到货 → 用完 → 一键预约顺丰上门取件
  → 归还 → 押金原路退回
```

#### 旅程 3：发布闭环（核心供给）

```
打开 APP → 点中央「+」FAB
  → 选择照片（最多 36 张/卷）→ 预览排序
  → 写文字描述 → 填写胶片信息卡（相机/胶卷/工艺）
  → 选话题（最多 3 个）→ 选可见范围（公开/仅关注/私密草稿）
  → 发布 → 跳回 Feed 首页 → 新笔记自动显示在「最新」Tab 顶部
```

## 6. 功能需求详述

### 6.1 模块一：内容社区（Phase 0）

#### 6.1.1 发现 Feed

**页面**：发现 Tab 首页（主屏）
**入口**：APP 启动默认页 / 点击底部「发现」Tab
**功能**：瀑布流展示笔记卡片，支持最新/热门/关注三种排序。

**字段清单**：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 排序方式 | enum | 是 | 热门（默认）/ 最新 / 关注 |
| 当前话题筛选 | string | 否 | 默认「全部」，可点话题 Tag 进入 |

## 10. 非功能需求

### 10.1 性能

| 指标 | 要求 |
|---|---|
| 首屏加载 | < 1.5s |
| Feed 滚动 | 60fps |
| 图片加载 | < 2s（CDN 加速后） |
| 接口响应 | P95 < 500ms |
| 启动时间 | 冷启动 < 2s（小程序） |

### 10.2 兼容性

- 微信小程序：基础库 ≥ 2.30.0（覆盖 99% 用户）
- iOS APP：iOS 13+
- Android APP：Android 7+（API 24+）
- 微信版本：≥ 8.0

### 10.3 安全与合规

- 用户隐私合规（《个人信息保护法》）：注册需勾选协议 + 隐私政策。
- 支付合规：仅微信支付商户号（企业版）。
- 内容合规：
  - 图片 + 文字机审（接入微信内容安全 API + 自建敏感词库）。
  - 人工抽检：日均 UGC ≥ 200 时启用。
  - 违规处罚：警告 → 限流 → 封禁。
- 数据安全：
  - 用户手机号、身份证号加密存储（AES-256）。
  - 微信 openid、unionid 仅用于登录，不外传。
- 反爬：核心 API 限流（IP 维度 100 QPS）。

### 10.4 可用性

- 核心服务可用性 ≥ 99.5%（轻量服务器单点）。
- 数据库每日自动备份，保留 30 天。
- 故障恢复时间 ≤ 30 分钟。

### 10.5 可维护性

- 前后端代码 TypeScript 全量覆盖。
- 接口文档自动生成（Swagger/OpenAPI）。
- 错误日志接入 Sentry。
- 关键业务流程埋点覆盖率 100%。

### 10.6 国际化（Phase 3 考虑）

- MVP 仅中文。
- 预留 i18n 框架。

|---|---|
| 无网络 | 顶部 Banner「网络异常」+ 缓存数据可用 |
| 接口超时 | Toast「加载失败，点击重试」 |
| 接口 5xx | 自动重试 1 次，失败后 Toast |
| 接口 4xx | Toast 用户可读错误信息 |

### 11.2 业务异常

| 场景 | 处理 |
|---|---|
| 库存不足 | 弹窗「商品已售罄」+ 推荐相似 |
| 重复下单 | 拦截 + 提示 |
| 订单超时未支付 | 30 分钟自动取消，库存释放 |
| 重复点赞/评论 | 服务端幂等，客户端即时反馈 |
| 用户被封禁 | 登录态失效，提示「账号异常请联系客服」 |
| 内容违规 | 机审拦截 + 人工复核 + 通知用户 |

### 11.3 边界场景

| 场景 | 处理 |
|---|---|
| 单条笔记 36 张图 | 上传分批（每批 6 张），进度条 |
| 长文 2000 字 | 字数统计 + 截断 |
| 同一时刻大量点赞 | 异步队列，UI 即时反馈 |
| 微信支付中途断网 | 客户端轮询查询订单最终态 |
| 用户切换城市 | 列表刷新 + 缓存清理 |

## 12. 验收标准

### 12.1 功能验收（DoD）

每个模块上线前必须满足：

- [ ] PRD 中所有字段、规则、状态机实现完毕
- [ ] 单元测试覆盖率 ≥ 60%（关键路径 ≥ 80%）
- [ ] 接口文档同步更新
- [ ] 边界场景全部测试通过
- [ ] 异常处理全部覆盖
- [ ] 埋点全部接入
- [ ] 通过设计走查
- [ ] 通过产品验收

### 12.2 性能验收

- [ ] Lighthouse 评分 ≥ 80（Web）
- [ ] 小程序首屏 < 1.5s
- [ ] 滚动 60fps（Chrome DevTools Performance 验证）
- [ ] 接口 P95 < 500ms

### 12.3 安全验收

- [ ] 等保 2.0 二级合规（ICP 备案）
- [ ] 隐私政策审核通过
- [ ] 内容审核通过（机审 + 人工）

- [ ] 邀请 5-10 个真实 KOL 体验，发卷流程顺畅
- [ ] 邀请 3-5 个潜在用户做租赁/电商/冲扫流程测试
- [ ] NPS ≥ 40
