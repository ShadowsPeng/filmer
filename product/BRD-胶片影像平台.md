## 1. 背景与项目目标

### 1.1 市场背景

- 胶片复兴趋势持续，增量用户集中在 18-30 岁，以学生和文艺青年为主
- 国内尚无一款覆盖「内容社区 + 电商 + 会员」的胶片垂直平台
- 现有玩家各自为战：NOMO/FIMO 只做滤镜，画英雄只做冲扫，闲鱼只做交易——没有一站式平台
- 胶片用户有多个高价值变现场景尚未被整合：相机租赁、冲扫服务、实体输出、防潮寄存等

### 1.2 项目愿景

> 做国内最大的胶片爱好者一站式平台——**不只是工具，是胶片生活方式入口**

### 1.3 产品目标

| 维度 | 目标 |
|---|---|
| 用户规模 | 上线 12 个月后注册用户破 50 万 |
| 社区活跃 | 日活 DAU ≥ 5 万，UGC 日均发帖 ≥ 2000 |
| 电商 GMV | 上线 6 个月后月 GMV 破 500 万 |
| 会员收入 | 上线 12 个月后会员订阅年收入破 500 万 |
| 租赁 GMV | 上线 12 个月后月租赁 GMV 破 100 万 |

## 2. 产品概述

### 2.1 产品定位

一款面向中国胶片爱好者的**内容社区 + 垂直电商 + 会员订阅 + 租赁服务**综合平台。

- **一句话定位**：胶片玩家的小红书 + 京东 + 滴滴租相机
- **目标用户**：18-35 岁胶片爱好者、摄影师、文艺青年
- **核心差异化**：国内唯一同时覆盖内容、电商、会员、租赁四大场景的胶片垂直平台

### 2.2 核心使用场景

```
用户 A（新手）：
刷社区看到好片 → 被种草胶卷型号 → 直接下单购买 → 晒出自己的第一卷 → 形成闭环

用户 B（老法师）：
参与话题讨论 → 分享反转片拍摄经验 → 租一台哈苏拍片 → 平台代冲扫 → 返图发社区

用户 C（犹豫入坑）：
订阅新手盒子（入门卷+教程+冲扫券）→ 试拍 → 决定买自己的相机
```

## 3. 功能需求详情

### 3.1 模块一：图片分享社区

#### 3.1.1 核心功能

| 功能 | 描述 |
|---|---|
| 发布笔记 | 图片 + 文字，支持多图（最多 9 图），可 @其他用户、打标签 |
| 发现 Feed | 瀑布流，支持按「最新 / 关注 / 热门」排序 |
| 话题广场 | 官方话题（#今日冲洗 #我的第一卷 #反转片挑战） |
| 胶片信息卡 | 每张图自动挂载：胶卷型号、相机、冲扫店、参数（ISO/光圈/快门） |
| 用户主页 | 晒图列表、粉丝数、关注数、个人简介 |
| 互动 | 点赞、评论、收藏、分享 |

#### 3.1.2 胶片信息卡（核心差异化）

用户上传图片时，引导填写：
- 胶卷品牌及型号（如 Kodak Portra 400、Fuji Velvia 50）
- 相机品牌型号（如 Hasselblad 500CM）
- 冲扫店（若有）
- 拍摄参数（ISO / 光圈 / 快门，可选）

→ 这些数据沉淀后可做「胶卷销量榜」「最热胶片」「各城市冲扫价格对比」等数据产品

#### 3.1.3 优先级

**P0（上线必做）**：发布、Feed、点赞评论、话题广场
**P1（3个月内）**：胶片信息卡、数据榜单、用户主页优化
**P2（6个月内）**：直播（胶片冲扫过程直播）、挑战赛功能

### 3.2 模块二：胶片 & 相机租赁

#### 3.2.1 背景与定位

胶片用户有两大租赁需求：
- **相机租赁**：徕卡/哈苏/富士中画幅日租金高，客单价可观（徕卡 M6 日租 ¥150-200）
- **胶卷租赁**：反转片单卷贵（¥80-150），新手想试但不想囤一整盒

#### 3.2.2 核心功能

| 功能 | 描述 |
|---|---|
| 相机租赁库 | 按品牌/型号/画幅筛选，展示日租金、可租数量 |
| 胶卷租赁库 | 按品牌/型号/感光度筛选，展示日租金、押金 |
| C2C 出租 | 用户把自己的闲置相机/胶卷挂上来，平台抽佣 15% |
| 归还与冲扫 | 租客拍完可选择：自行冲扫 → 归还空卷；或寄回平台 → 代冲扫 |
| 押金制度 | 高价设备需付押金，归还后全额退还；平台提供损坏险（可选，¥10/天） |
| 租赁套餐 | 「新手体验包」含入门相机 3 天租赁 + 1 卷 Portra 400 + 冲扫代金券 |

#### 3.2.3 品类规划

**相机租赁：**

| 品类 | 代表 SKU | 日租金（预估） | 押金 |
|---|---|---|---|
| 入门旁轴 | 富士 Klasse、Contax T2 | ¥30-50 | ¥300 |
| 专业旁轴 | 徕卡 M6、徕卡 MP | ¥150-200 | ¥2000 |
| 中画幅 | 哈苏 500CM、玛米亚 RB67 | ¥100-150 | ¥1500 |
| 大画幅 | 沙穆尼、林哈夫 | ¥300-500 | ¥5000 |

**胶卷租赁：**

| 品类 | 代表 SKU | 日租金（预估） | 押金 |
|---|---|---|---|
| 入门负片 | Kodak UltraMax、Fuji C200 | ¥5-8/卷 | ¥30 |
| 专业负片 | Kodak Portra 400、Kodak Ektar | ¥10-15/卷 | ¥60 |
| 反转片 | Fuji Velvia 50、Kodak E100 | ¥20-30/卷 | ¥150 |
| 特殊胶卷 | Lomo 胶卷、过期胶卷 | ¥3-5/卷 | ¥20 |

#### 3.2.4 商业模式

- **租金收入**：日租金 × 租赁天数，平台抽佣 15-20%
- **押金沉淀**：押金在归还前沉淀为流动资金
- **冲扫增值服务**：租客选择平台代冲扫，收取冲扫费（¥15-40/卷，含扫描）
- **损坏险**：平台提供可选保险，¥10/天/台，覆盖意外损坏

#### 3.2.5 优先级

**P0**：相机 + 胶卷租赁库上下线、押金管理、订单流程、C2C 出租功能
**P1**：代冲扫服务上线、租赁套餐
**P2**：企业租赁套餐（工作室批量租赁）、租赁排行榜

### 3.3 模块三：胶片电商

#### 3.3.1 商品品类

| 品类 | 示例 SKU | 供应链难度 |
|---|---|---|
| **胶卷（135/120/大片幅）** | Kodak Portra 400、Fuji Pro 400H、Ilford HP5 | 高（货源不稳、价格波动大） |
| **反转片** | Kodak E100、Fuji Velvia 50 | 极高（国内货源稀缺） |
| **冲洗套药/相纸** | 显影液、定影液、RC相纸 | 中（可从影视耗材渠道拿货） |
| **胶片周边器材** | 胶卷收纳盒、暗袋、冲洗罐、计时器 | 低（标品，可一件代发） |
| **相机配件** | 测光表、胶片背纸、观片器 | 低-中 |

#### 3.3.2 供应链策略

**胶卷是核心引流品，但毛利低、货源不稳**：
- 先从「周边器材 + 套药」切入，标准化程度高
- 胶卷采购前期对接**感光故事、影视狗**等现有供应商，**不做自库存**，走一件代发
- 反转片做「预售 + 团购」模式，聚合需求后统一采购，降低风险

#### 3.3.3 电商核心功能

| 功能 | 描述 |
|---|---|
| 商品详情页 | 图片、参数、用户评价、相关笔记（种草内容直接挂购买链接） |
| 购物车 + 订单 | 标准电商流程，支持优惠券 |
| 积分体系 | 购物积分、发帖积分，可抵扣 |
| 会员专享价 | 会员专属折扣（见 3.4） |
| 预售功能 | 反转片等稀缺品支持预售 |

#### 3.3.4 优先级

**P0**：器材周边（先跑通供应链）、购物车、订单
**P1**：胶卷上架（重点引流品）、种草笔记挂商品链接
**P2**：反转片预售、反向海淘（海外胶卷代购）

### 3.4 模块四：胶片冲洗服务

#### 3.4.1 背景与定位

冲洗是胶片拍摄后**必经的线下环节**，用户痛点明确：不知道哪家冲扫店靠谱、不知道流程、不能线上追踪进度。本平台做**冲扫服务的线上化**。

#### 3.4.2 核心功能

| 功能 | 描述 |
|---|---|
| 冲扫店入驻 | 线下冲扫店注册入驻，展示价格、擅长工艺、用户评分 |
| 委托下单 | 用户选择冲扫店 → 寄出胶卷 → 平台追踪物流 → 冲扫进度可视化 → 完成后返图 |
| 冲扫套餐 | 基础冲洗 + 扫描、精细校色、反转片冲洗等分层套餐 |
| 评价体系 | 用户对冲扫店评分 + 返图质量评价 |
| 积分抵扣 | 冲扫费用可用积分折抵 |

#### 3.4.3 商业模式

- **平台抽佣**：每笔冲扫订单抽取 10-15% 服务费
- **物流整合（可选）**：与顺丰/京东合作胶卷专线，降低用户寄件门槛，平台贴部分运费作为会员权益

#### 3.4.4 优先级

**P0**：冲扫店入驻 + 委托下单流程
**P1**：物流追踪、冲扫进度可视化
**P2**：自营冲扫工坊（Phase 3 可考虑）

### 3.5 模块五：会员体系

#### 3.5.1 会员等级

| 等级 | 价格 | 核心权益 |
|---|---|---|
| **免费** | 0 | 浏览社区、购买商品、基础积分 |
| **银会员** | ¥29/月或 ¥259/年 | 会员专享价（电商全场 95 折）、每月一张冲扫代金券（¥20）、专属客服、租赁免押金券（每月1张） |
| **金会员** | ¥79/月或 ¥699/年 | 全场 9 折、每月冲扫代金券（¥50）、新品优先购（反转片预售优先权）、线下活动名额、租赁免押金券（每月3张） |

#### 3.5.2 会员权益设计逻辑

- **折扣是最直接留存动机**，银会员每年省 259×0.05≈130 元，刚性可算
- **冲扫代金券**是钩子——引导用户使用平台冲扫服务（后续可自建或联营冲扫产能）
- **反转片优先购**是稀缺性权益，金会员专属，反向拉动会员转化
- **租赁免押金券**切中大额押金痛点，银会员每月 1 张可用于胶卷租赁免押金，金会员 3 张可用于相机租赁免押金
- 线下活动（胶片摄影外拍、冲扫工坊）是社交资产，提升金会员感知价值

#### 3.5.3 优先级

**P0**：银会员上线、支付订阅
**P1**：金会员、反转片优先购、免押金券
**P2**：线下活动名额系统、会员等级徽章

### 3.6 模块六：增值变现方向

#### 3.6.1 实体照片输出

**背景**：冲扫后只返数字扫描，但很多用户想要实体照片——尤其反转片的幻灯片效果，在观片器上看的质感完全不同。

| 功能 | 描述 |
|---|---|
| 银盐打印 | 对接 PhotoLab，提供 4R / 5R / A4 银盐打印 |
| 相册定制 | 用户可将某次冲扫的照片定制为手工相册，作为礼物 |
| 幻灯片装裱 | 反转片冲扫后可定制灯箱装裱，高毛利定制产品 |

**优先级**：P2（需要对接实体输出供应商）

#### 3.6.2 防潮寄存服务

**背景**：高价胶卷（过期反转片）和老相机怕潮，南方用户有真实需求。

| 功能 | 描述 |
|---|---|
| 胶卷/相机寄存 | 小型密封存储柜，按月收费 ¥20-50/月 |
| 在线查看 | 用户可在线查看自己寄存的胶卷清单，增强粘性 |
| 到期提醒 | 胶卷到期前推送提醒，引导再次消费 |

**优先级**：P2（可联营第三方存储服务商）

#### 3.6.3 新手订阅盒

**背景**：想入坑的新手不知道买什么，订阅盒降低决策门槛。

| 产品 | 内容 | 价格 |
|---|---|---|
| 新手入门盒 | 1 卷入门卷（Portra 400/C200）+ 显影试条 + 冲扫指南 + 平台体验会员券 | ¥199/次 |
| 季度摄影盒 | 4 卷精选胶卷 + 1 本杂志 + 1 个周边小件 | ¥599/季度 |

**优先级**：P2（供应链整合复杂，建议联营）

#### 3.6.4 品牌联名 & 限量发售

**背景**：胶片圈对联名很买账（Kodak × 潮牌每次秒空），平台可做中间商撮合小众品牌做限量礼盒。

| 形式 | 描述 |
|---|---|
| 限量礼盒 | 撮合小众胶片品牌 / 复古相机品牌做联名礼盒，平台抽佣 + 话题流量 |
| 抽签购买 | 稀缺品（停产反转片、绝版相机）用抽签模式，话题度和溢价都高 |

**优先级**：P2（需要品牌资源积累）

#### 3.6.5 数据产品

**背景**：社区沉淀的胶片数据（什么卷最热、哪个城市冲扫最便宜）本身有价值。

| 产品 | 描述 |
|---|---|
| 胶片热度榜 | 月度「最热胶卷」「最热相机」榜单，免费提供吸引流量 |
| 冲扫价格地图 | 各城市冲扫店价格对比，数据可卖给器材品牌 |
| 新手指南报告 | 基于 UGC 数据分析生成，付费 ¥9.9 或会员免费解锁 |

**优先级**：P2（需要较大用户基数）

## 7. 风险与对策

| 风险 | 等级 | 对策 |
|---|---|---|
| 胶卷货源不稳定（厂商供货波动） | 高 | 先做器材周边，胶卷逐步扩展；联营多家供应商 |
| 社区冷启动（没有内容就没有用户） | 高 | 邀请 KOL 入驻（胶片摄影师）、举办话题挑战赛 |
| 供应链垫资压力大 | 中 | 先走代发模式，GMV 起来后再考虑自库存 |
| 会员转化率低 | 中 | 银会员门槛低，用「首次下单减10元」引导升级 |
| 租赁资产损失风险（相机损坏/丢失） | 中 | 提供损坏险，用户购买后平台承担风险；高价值设备需验机入职和归还 |

## 7.1 增值变现方向（确认开展）

以下 5 个方向经评估可行，纳入产品规划：

#### 7.1.1 相机 & 胶卷租赁（C2C）

- 平台撮合个人用户之间出租相机/胶卷
- 平台抽佣 15%，不动用押金
- 详见 3.2 模块

#### 7.1.2 实体照片输出

- 冲扫后对接银盐打印（4R/5R/A4）、相册定制、反转片灯箱装裱
- 平台对接 PhotoLab 等供应商，按成交抽佣
- 高毛利定制产品，适合送礼场景

#### 7.1.3 新手订阅盒

- 「新手入门盒」：入门卷 + 显影试条 + 冲扫指南 + 会员体验券，¥199/次
- 「季度摄影盒」：4 卷精选胶卷 + 杂志 + 周边，¥599/季度
- 联营模式，平台不碰库存

#### 7.1.4 品牌联名 & 限量发售

- 撮合小众胶片品牌 / 复古相机品牌做限量礼盒，平台抽佣 + 话题流量
- 稀缺品（停产反转片、绝版配件）采用抽签模式，溢价高
- 长期积累品牌资源后发力

#### 7.1.5 数据产品

- 「胶片热度榜」：月度最热胶卷/相机榜单，免费提供，吸引流量
- 「冲扫价格地图」：各城市冲扫价格对比，数据可卖给器材品牌做市场决策
- 「新手指南报告」：基于 UGC 数据分析生成，¥9.9 或会员免费解锁
- 需要用户基数支撑，Phase 3 再上
